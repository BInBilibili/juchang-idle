# 菊厂放置 · 打工人摸鱼模拟器

一款**上班族主题**的放置类（Idle）网页游戏，玩法与数值结构参考 [Melvor Idle](https://melvoridle.com/)。
纯前端、零依赖、零构建，直接用浏览器打开就能玩，进度存在本地浏览器里。

> 你是菊厂的一名普通员工。白天在工位上和「模糊需求」「技术债幼龙」「Deadline 死神」搏斗，
> 晚上靠钓鱼、健身、打游戏、理财回血。所有技能都是 100 级上限。

## 玩法一览

### 7 大岗位战斗（每类 4 个区域 × 3 个敌人 = 84 个）

| 大类 | 区域（由浅到深） |
| --- | --- |
| ⌨️ 研发类 | 需求沼泽 → 代码熔炉 → 线上火线 → 架构深渊 |
| 📈 销售类 | 线索荒原 → 谈判桌 → 竞品战场 → 回款深渊 |
| 🎧 服务类 | 工单海洋 → SLA 时钟塔 → 故障风暴 → 客户怒火 |
| 🚢 供应链类 | 缺料沙漠 → 物流海峡 → 供应商迷宫 → 黑天鹅港口 |
| 🧾 财经类 | 预算峡谷 → 审计神殿 → 坏账墓地 → 汇率风暴 |
| ⚖️ 法务类 | 合同迷宫 → 合规法庭 → 诉讼火山 → 知识产权战场 |
| 👥 人力资源类 | 招聘荒原 → 绩效竞技场 → 离职潮 → 仲裁法庭 |

每个区域 3 个敌人：**普通 / 精英 / 区域 Boss**。
另有独立的 **🌍 世界 Boss 区域**：不确定性(Lv100) → 黑天鹅(Lv105) → Deadline(Lv110) → 经济周期(Lv115) → 地缘政治(Lv120)。

击败敌人掉落：**工资**、**摸鱼点**、**奶茶 / 咖啡**等消耗品，并有概率掉落**装备**。

### 8 项业余爱好（每项 100 级）

| 爱好 | 产出 | 作用 |
| --- | --- | --- |
| 🎣 钓鱼 | 各种鱼 | 烹饪的原料 |
| 🍳 烹饪 | 食物 | 战斗中回精力，续航核心 |
| 🏃 健身 | 体质点 | 永久 +精力上限（自动生效） |
| 🎨 艺术 | 灵感、收藏品 | 灵感工坊兑换永久加成 |
| 🎮 游戏 | 多巴胺、装备 | 多巴胺可在战斗中换取增益 |
| 💰 理财 | 工资 | 专职赚钱，有风险也有高收益 |
| 📚 阅读 | 知识 | 永久 +全技能经验（上限 +50%） |
| 🍻 社交 | 人脉 | 永久 +金钱与掉落率（上限 +50%） |

### 职场化的战斗系统

| 原版概念 | 本作说法 | 说明 |
| --- | --- | --- |
| Attack | **执行力** | 命中 |
| Strength | **抗压力** | 伤害 |
| Defence | **钝感力** | 闪避 |
| Hitpoints | **精力值** | 生命 |
| Melee | **执行力 / 当面沟通** | 用办公用品近身肉搏 |
| Ranged | **沟通力 / 远程沟通** | 邮件、IM、电话 |
| Magic | **汇报力 / 汇报输出** | PPT、周报、数据大屏 |
| Prayer | **摸鱼** | 消耗摸鱼点开启临时增益 |
| Slayer | **背锅** | 接锅任务，换背锅币买专属装备 |

战斗三角：**执行力 → 沟通力 → 汇报力 → 执行力**，克制方 +15% 命中、+10% 伤害。

### 其它系统

- **装备**：10 个部位 × 8 个档位，共 88 件。武器决定攻击风格，护具提供闪避 / 精力 / 减伤。
- **摸鱼**：15 种摸鱼姿势（刷手机、带薪如厕、窗口切屏、准点下班、躺平……），消耗摸鱼点换取增益。
- **背锅**：6 个档位的锅，完成后拿背锅币，可在背锅商店兑换 6 件专属装备。
- **灵感工坊**：8 项永久升级，用灵感兑换。
- **商店**：补给品、10 项永久升级、全部装备。
- **离线收益**：关掉页面也会按比例结算（最长 24 小时）。

## 运行

不需要安装任何东西，也不需要构建：

```bash
# 方式一：直接双击 index.html（部分浏览器会限制 ES Module，建议用方式二）

# 方式二：起一个静态服务器
npx serve .
# 或
python -m http.server 8080
```

然后打开 `http://localhost:8080`。

### 在线游玩

开启 GitHub Pages 后可直接访问：
`https://<你的用户名>.github.io/<仓库名>/`

## 数值是怎么定的

这个项目没有手拍数值，而是用「**玩家期望战力反推**」的方式生成敌人：

1. 先建模玩家在任意等级的期望面板（`tools/gen-enemies.mjs` 里的 `playerAt()`）：
   - 装备档位 `t(L) = floor((L-1)/14)`，共 8 档，属性指数增长（伤害 3 → 10308）
   - 命中等级 `(L+9) × (装备命中加成 + 64)`
   - 最大伤害 `10 × (2.2 + L/10 + (L+17) × 伤害加成 / 640)`
   - 精力上限 `L×10 + 装备精力加成`，减伤 = 装备减伤 + 0.15×L（上限 80%）

2. 再按目标手感反推敌人：
   - 玩家命中率 ≈ **80%**，敌人命中率 **45%~65%**
   - 普通怪 **3~16 刀**（随等级上升），精英 ×1.6，区域 Boss ×2.6，世界 Boss ×20
   - 玩家能扛的刀数：普通 14 刀 / 精英 10 刀 / Boss 6 刀 / 世界 Boss 3.5 刀
   - 基准玩家取「刚好能解锁这只怪的最低岗位等级」（`enemyLevel - 8`）

3. 敌人精力按经验曲线 `2^(L/7)` 同步指数化，保证每级大致需要 8~15 次击杀。

改完 `js/data/items.js` 里的 `TIER_BASE` / `SLOT_MUL` 之后，**必须重跑**：

```bash
node tools/gen-enemies.mjs
```

否则敌我数值会脱节。

### 自检命令

```bash
node tools/gen-enemies.mjs          # 重新生成敌人数据
node tools/test-sim.mjs             # 校验经验表、面板、命中率、掉落、活动产出
node tools/test-progression.mjs rd 24   # 模拟「研发类」挂机 24 小时的升级曲线
node tools/test-ui.mjs              # 把全部 24 个视图渲染一遍，抓运行时错误
```

## 存档

进度保存在浏览器 `localStorage`（键名 `juchang-idle-save-v1`），每 10 秒自动存一次，
切后台与关闭页面时也会存。

换设备时在「设置 → 导出存档」复制文本，到新设备「导入存档」粘贴即可。
